RIAC email signatures

Ready to copy into Outlook. The logo is built into the signature, so it shows up for everyone — including people writing to us for the first time.

Why this page exists. The old signature didn’t contain the logo — it contained a link to the logo on nyriac.com. Outlook, Gmail and the rest block downloaded pictures from senders you haven’t written to before, so those recipients saw an empty box with blue text instead of the RIAC map. The signatures below carry the picture inside the message, so there is nothing left to block.

How to set it up

These steps are for new Outlook and Outlook in a web browser (both work the same way). You’ll do this once per person.

  1. Scroll down to the signature you want and select it — click just above and left of the logo and drag to just below and right of the navy bar, so the whole block is highlighted. Then press Ctrl + C to copy.
  2. In Outlook, click the gear icon (top right) → Mail → Compose and reply.
  3. Under Email signature, give it a name (e.g. “RIAC”), click into the big editing box, and delete anything already in there.
  4. Press Ctrl + V to paste. The logo and layout should appear.
  5. Type over the placeholder details in square brackets with the real name, title, direct line and email address.
  6. Underneath, set both dropdowns to your new signature — one is for new messages, the other for replies and forwards. If the second one is left blank, the signature won’t appear on replies at all.
  7. Click Save.
Then test it, please. Send an email to a personal address — a Gmail or Yahoo account, ideally one that has never received mail from you at work. If the map shows up there without you clicking anything, it’s fixed. I can’t check this from my end, so you are the only one who can confirm it.

If the logo doesn’t survive the paste

Occasionally a browser drops the picture when copying. If that happens: paste as above, delete the broken picture, then save the logo file to your computer (right-click → Save image as…) and use the picture button in the signature toolbar to insert it from there. That produces exactly the same result.
